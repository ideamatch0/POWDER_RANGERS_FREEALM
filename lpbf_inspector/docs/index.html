What this version does

Powder Ranger helps process teams inspect large image volumes from LPBF powder-bed monitoring and focus review time on the most relevant layers instead of scrolling through thousands of files.

Single-job analysis

Load one build job, calibrate once on intra-job grayscale level, and run layer-by-layer analysis in one pass.

Spread + Melt views

Separate analysis and visualization for recoater/spread and post-melt images, with stable layer mapping and per-stage metrics.

Priority scoring

Each detection gets a score from 0 to 100 by combining intensity rise and persistence across consecutive layers.

Faster review flow

Sort by timeline or score, move quickly through detections, and log decisions directly during review.

3D stack explorer

Reconstruct a layered volume preview, tune slice depth and density, and inspect retained indications in 3D context.

Offline-first

No image upload to the cloud by default. Source photos remain local; analysis can be performed on any standard office workstation.

Built for practical usage

The tool was designed around day-to-day operator and engineering review:

  • Layer-level highlighting with image context (before, flagged layer, after).
  • Consecutive-layer persistence filters to suppress one-off noise.
  • Automatic ROI focus when needed to keep decisions fast.
  • Dedicated report export of retained indications only.
  • Mode selection at launch: independent job analysis and comparison workflow stub.

Security and deployment notes

Local mode is suitable for confidential shop-floor environments. Public hosting is possible for demos using a controlled deployment profile.

  • Offline-first processing by default
  • No mandatory cloud storage of build images
  • Suitable for internal LAN deployment
  • Release packaging in Windows executable
