What this version does

Powder Ranger helps process teams inspect large image volumes from LPBF powder-bed monitoring and focus review time on the most relevant layers instead of scrolling through thousands of files.

Single-job analysis

Load one build job, calibrate once on intra-job grayscale level, and run layer-by-layer analysis in one pass.

Spread + Melt views

Separate analysis and visualization for spread and post-melt images, with stable layer mapping and per-stage metrics.

Priority scoring

Each indication is scored from 0 to 100 by combining intensity rise and persistence across consecutive layers.

Faster review flow

Sort by timeline or score, move quickly through detections, and log decisions directly while reviewing.

3D stack explorer

Reconstruct a layered volume preview, tune depth and density, and inspect retained indications in 3D context.

Offline-first

No mandatory image upload. Source photos remain local; analysis can run on standard office workstations.

Built for practical use

Designed for day-to-day operator and engineering review in production labs:

  • Layer highlighting with local context (before, flagged layer, after).
  • Consecutive-layer persistence filters to suppress one-off noise.
  • Auto-zoomed ROI previews around suspicious regions.
  • Dedicated report export with only retained indications.
  • Mode selection at launch: independent job analysis and reference-comparison mode.

Security and deployment notes

Local processing is designed for confidential environments. Public hosting can be used only for demo and documentation.

  • No mandatory cloud storage of build images
  • Offline-first processing by default
  • Suitable for internal LAN deployment
  • Windows executable release available
